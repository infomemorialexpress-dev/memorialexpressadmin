# Memorial Express - Admin Dashboard

Independent React + Vite management dashboard for administrators to manage partner funeral homes and pricing schedules.

## Tech Stack
- React 19
- Vite
- React Router v7

## Getting Started
```bash
npm install
npm run dev
```
Port: `http://localhost:5174`

## Authentication
- **Demo PIN**: `1234`
- **Demo Credentials**: `admin` / `admin123`

## Features
- Protected security route gateway
- Dedicated POST/PUT mutations for partner funeral homes
- Real-time casket & add-on pricing editor
- JSON catalog export & import
- Reset to demo catalog data
